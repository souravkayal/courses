# Gen AI / Applied AI — Course Website

Simple single-page static site for the 4-week Gen AI / Applied AI course.

## Run locally

Just open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Host on GitHub Pages

1. Push this folder to `https://github.com/souravkayal/courses` (branch `main`, root `/`).
2. On GitHub: repo **Settings → Pages → Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)**
3. Site will be live at `https://souravkayal.github.io/courses/`
