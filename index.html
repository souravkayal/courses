Curriculum

2 sessions per week · hands-on throughout

Week 1

Python, LLMs & Prompting Foundations

Session 1

  • Python basics to advance
  • Introduction to Applied AI / ML
  • Understanding of Generative AI and LLMs
  • Work with prompts, context and structured output

Session 2

  • Chain-of-Thought prompting and Few-shot prompting
  • Prompting reliably
  • Prototypes and demonstrations of local models using Ollama / LM Studio
  • Consume local models using API and build chat application
Week 2

Retrieval-Augmented Generation (RAG)

Session 1

  • Introduction to RAG
  • Building RAG application using custom dataset
  • Fundamentals of semantic search

Session 2

  • Advanced RAG with metadata filtering
  • Hybrid search in RAG
  • Query re-writing
  • Semantic cache
Week 3

Agentic AI & Evaluation

Session 1

  • Building Agentic RAG and multi-decision framework
  • Agentic loop (ReAct / Reason + Act, Observe–Think–Act)
  • Workflow of agentic applications

Session 2

  • Define evaluation framework for Agent / RAG
  • Project on agentic framework
Week 4

Bridge Course / Module

Career + Real Projects

Session 1 — Interview preparation

  • Interview preparation for software engineering roles
  • Tools and sample questions
  • Interview formats / mock interview
  • Discussion on current trending technologies

Session 2 — Real projects & mentorship

  • Experience in real projects with latest tools and technologies
  • Mentor and guidance on interview preparation

What you'll build

  • Chat app on local models (Ollama / LM Studio)
  • RAG app on a real dataset with hybrid search
  • Agentic RAG project with evaluation / guardrails and instrumentation
Ollama LM Studio RAG Hybrid Search Agents / ReAct

Who is this for?

Learners with Python fundamentals who want practical, applied Gen AI skills — prompting, RAG, agents — and career guidance for software engineering roles.
